# AttaLambda 0.8.0 — milestone in progress

Version metadata is prepared on `interactive-attalambda`. This is not a verified
candidate or published release. The full current-source and exact Linux standalone gates
remain unfinished; [PLAN.md](../../PLAN.md) and [HANDOFF.md](../../HANDOFF.md)
record the current evidence and next step. Published downloads remain 0.7.0.

## Implemented source changes

- `(read-line UNIT)` supplies byte-preserving runtime input through the existing
  host, with lazy sharing, `OK(SOME(String))`, and `OK(NONE)` at EOF.
- No-file startup provides the `atta>` shell on a terminal. Explicit `--repl`
  permits redirected transcripts; `--no-history` disables persistent history.
- Six commands provide help, committed-name listing, standalone file loading,
  echo control, reset, and quit. Successful definitions remain lazy; earlier
  closures keep their captured bindings across redefinitions.
- The terminal editor handles multiline entries, editing, cancellation, input
  handoff, source-history recall, and completion from public and committed names. It runs no personal initialization files.
- Automatic echo uses the existing pure renderer. Use `:echo off` for raw
  functions: their rendering behavior remains unspecified.

The [API guide](../API.md#interactive-shell-unreleased) gives exact source,
input, history, and exit-status behavior. Existing files keep their
`#lang attalambda` declaration and execute without automatic expression echo.
Rat representations, unary-lambda purity, the public names, recursion rules,
and the old file/TCP/printing operations are preserved. No input-only release,
new evaluator, optimizer, package manager, or additional public binary platform
is introduced.
