## What changed

### `list-case`

`(list-case list cons-function nil-value)` is a public List eliminator. It is
strict on the List and lazy on both branches: `NIL` selects `nil-value` without
applying the function, and `(cons h t)` returns `((cons-function h) t)` without
evaluating `nil-value`. The callback's result is returned untouched. A non-List
argument produces `ERROR(list-case(arg1 expected LIST got <TAG>))`; an Error
argument propagates with the `list-case` frame. It is built only from existing
pure pieces and is a chain of unary lambdas, so partial application works as
for every other builtin.

Its static contract is complete,
`forall a:data b. List(a) -> (a -> List(a) -> b) -> b -> b`, which is what the
eliminator buys:

```racket
(rec sum xs = (list-case xs (lambda (h t) (add h (sum t))) 0))    ; FULL PASS, sum : List(Rat) -> Rat
(rec sum xs = (if (is-nil xs) 0 (add (head xs) (sum (tail xs)))))  ; PARTIAL, two UNREPRESENTED_ERROR_ALTERNATIVE
```

`head` and `tail` are unchanged and remain partial by design: their empty-list
Error is not represented in their types.

### Type-system selection

`attalambda --check FILE.attl` is unchanged and means `--check=hm`.
`attalambda --check=hm FILE.attl` and `attalambda --check=simple FILE.attl` are
the explicit spellings; any other `--check=` token is command misuse
(status 64). The report prints one new line, `System: hm` or `System: simple`,
directly after `Scope:`. Nothing else in the report changes, and every verdict,
count, diagnostic, and status under `hm` is identical to 0.9.0. The help text
gains `attalambda --check=SYSTEM FILE.attl`.

### The `simple` system

`simple` is the same inference engine with generalization switched off: `def`,
`rec`, and source `let` bindings are monomorphic, one solution state is shared
across the file (definitions in dependency order, then top-level expressions),
and signatures reflect the final state; an unfixed variable is shown as a letter
without `forall`. Built-in contracts keep their audited polymorphic types under
both systems. It is the simply typed lambda calculus over a library of
polymorphic constants, not System F. The same file can pass under `hm` and fail
under `simple`:

```racket
#lang attalambda
(def identity x = x)
(identity 1)
(identity "text")
```

`--check`: `FULL PASS`, status 0, `identity : forall a. a -> a`.
`--check=simple`: `FAIL`, status 1, one `TYPE_CONFLICT` at line 4,
`identity : Rat -> Rat`, `Definitions: 1/1`.

### Fixes to file-run, effects, and the checker

- The module reader's body read is locked, so a `#reader` extension in a source
  file can no longer run host code.
- A launched file is always compiled from source, never from a `compiled/`
  bytecode file planted beside it.
- Ctrl+C during a run prints one line and exits 130 instead of a stack trace.
- File-run syntax failures report the user's own position and escape control
  characters; a repeated `def` is reported as a duplicate at its later
  occurrence; a closed stderr no longer changes the exit status.
- The dotenv refusal matches only a path component named `.env` or starting
  with `.env.`; a name that merely contains `env` runs like any other program.
- `write-file` is atomic: bytes land in a temporary file renamed over the
  target, a failed write leaves the target intact, an existing target keeps its
  permission bits, and a symbolic link at the target is replaced by a regular
  file.
- `tcp-listen` enables address reuse, so a port is bindable again right after
  shutdown.
- The static checker keeps a callable requirement on an operator whose
  argument is unproved, so that conflict is reported in either use order.
- The `--check` report no longer prints the column-convention parenthetical or
  the three trailing "Trusted basis" sentences.

## Compatibility

All changes are additive to the language. `list-case` is the only new public
name; no existing name, representation, or runtime behavior changes. Existing
`--check` invocations produce the same verdicts, counts, diagnostics, and exit
statuses with one added `System: hm` line; tools that parsed 0.9.0 reports by
line number must account for it, and for the removed trailer. The audited
inventory is now 130 bindings, 107 complete and 23 partial. No annotation
syntax, function tag, host detection, product type, or tagged union is added.
Linux x86-64 remains the only supported binary download.

## Known limits

`simple` treats built-ins as polymorphic constants and removes no polymorphism
from the library; letters restart at `a` in every displayed signature, and a
`:data` restriction on an open variable is enforced but not displayed. `head`,
`tail`, and count-based List operations remain partial under both systems. A
raw function inside a container remains unspecified at runtime and is excluded
statically under both systems. Applying a non-function, including a
wrong-arity `list-case` callback, diverges at runtime as in any untyped lambda
calculus; `--check` reports it.
