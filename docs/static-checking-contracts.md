# Optional static checking: audited built-in contracts

This inventory describes the static checker released in 0.9.0. The single implementation is [`runner/static/contracts.rkt`](../runner/static/contracts.rkt). All 129 actual public value bindings are classified: 106 complete and 23 partial; none remains pending. Syntax and private scaffolding are excluded. The export test reads the real facade and checks its resolved bindings against this inventory. Every analysis validates the catalog before inference.

Complete contracts are trusted, audited input preconditions and normal result shapes; the checker does not re-infer library implementations or prove termination, resource availability, or external success. Existing runtime checks and algorithms are unchanged. `Result(a)` contains Ok of `a` or Err of Error; Error is not an unconstrained second parameter.

`a:data` restricts a quantified variable to canonical non-Error Rat, Bool, String, Char, Byte, Unit, and recursively supported List, Option, Result, or Map shapes. Raw functions and Error payloads are outside this domain. A Result's fixed Err payload remains Error. Map also carries an audited key comparator returning Bool; its uncertainty taints the Map even while empty.

**Partial rows never provide verified output types.** Their displayed shape retains audited input obligations plus an explanatory result hint. The input arity bounds that hint: after the known inputs are consumed, it cannot become another callable obligation or an inferred signature. The reason identifies the missing proof. Bare partial bindings, aliases, closures, and higher-order uses retain the gap.

Generic rendering and print use the restricted data contract. Direct Error rendering has the explicit `error-to-string` contract; broader overloads are not silently inferred. Lists are homogeneous, String is nominally distinct from List(Char), and zip returns two-element Lists, not a Pair. Flatten's arbitrary change in nesting is outside the finite type relationship.

The four complete I/O wrappers were traced through facade injection, pure wrappers, host branches, and canonical codec construction. Expected I/O failures return Result Err. TCP numeric validation can instead return Error before host dispatch, so those contracts remain partial. The HTTP parser and response renderer use Result Err for malformed requests or unsupported status values; the factories with an explicitly injected host retain an unsupported-protocol gap.

Implementation locators below name actual definitions, checked by `tests/static-contracts-test.rkt`. The focused tests cover valid and invalid runtime domains separately from static analysis; no user program is executed to infer its type. Additional static counterexamples are in `tests/static-*-test.rkt`. Focused and checkpoint commands/results are recorded in [PLAN.md](../PLAN.md).
